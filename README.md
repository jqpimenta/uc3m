## Notes on Replicating the Analyses

All data need to be downloaded from the original sources first and the paths adapted in the analysis files. The  data sources can be found in the corresponding papers.

### AQMSS2 & PE
Create the data in the following order (all files are in the create_data folder):

1. bolsafamilia.R
2. acled.R
3. panel.R

Then, run the analysis.R file, which contains the final analysis that uses the data created from the scripts in the create_data folder.
